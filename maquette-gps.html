MAQUETTE — action 2 (feu vert visuel)
Bouton, barre et marqueur = code réel prévu ; la position est simulée (vol au cap autour de LFPN, accéléré ×20). Clique GPS : suivi continu (avion + carte centrée). Déplace la carte : le centrage se coupe, le bouton devient Recentrer (l'avion reste). Re-clique GPS : arrêt. Voyant écran maintenu allumé = Wake Lock automatique.
Pendant le suivi, une trace magenta enregistre le trajet parcouru : effacée à chaque nouveau démarrage du GPS, conservée à l'arrêt. Vérifie l'orientation : au cap 000°, le nez de l'avion doit pointer vers le HAUT.
Position indisponible : autorise la localisation de ce site dans ton navigateur (icône cadenas → Autorisations → Localisation).
